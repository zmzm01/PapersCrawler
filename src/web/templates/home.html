About

PapersCrawler automatically tracks 21 journals from 7 publishers through an 8-phase pipeline — discovery, metadata enrichment, page scraping, relevance filtering, PDF parsing, structured summarization, report generation, and email delivery.

Quick Guide

Page What you can do Notes
Pipeline View pipeline status, run via tools/run_pipeline.py. Config SKIP toggles disable Pipeline buttons. Reset shows impact details.
Dashboard View pipeline status charts, paper counts, pending report stats and error breakdowns (read-only). Auto-refreshes every 10s. Shows real-time pipeline health.
Papers Browse papers, filter by category, sort by date. Reports generated by tools/preview_report.py.
Report View generated reports, filter by source and date. Reports are grouped by auto/user source and sorted by date. Use the sidebar or dropdown to open one.
Logs View pipeline log file, filter by severity level (read-only). Shows most recent ~200 KB. New log lines via SSE.
